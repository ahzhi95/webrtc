# Lovely House 幼儿园 App

给幼儿园（多个校区）用的手机网页 App：

1. **到园 / 离园**：老师在班级名单上勾选点名（时间自动填入，可以修改，提交前确认），或者扫学生的二维码卡。超过设定时间会标记“迟到”。修改已提交的时间必须填写原因，并保留修改记录。
2. **通告**：发给全部学校、某个校区或某个班；可以加图片 / PDF 附件、定时发布、修改、撤回，并查看谁已读、谁未读。
3. **缴费**：学校建立收费项目（月费、活动 / 临时收费、杂费），发给整个校区、一个班或指定学生，截止日期可不填。超过一个月未缴（或过了截止日期）会提示，管理员按“提醒”就会通知未缴的家长。家长勾选已付的项目，上传一张凭证；学校确认后项目变成“已缴”，退回时必须写原因。也可以记录现金付款、免缴，或修改个别学生的金额。
   管理员确认后，系统自动开立**正式收据**（每个校区自己编号，例如 `TTM-2026-0001`），家长可以下载 PDF 或图片。付款被撤销时收据会标记“已作废”，号码不会重复使用。收据上的学校名称、注册编号、地址、电话在 **管理 → 校区** 填写。
4. **学生照片**：老师上传照片，选出照片里有哪些学生、场景和拍摄日期，**只有这些学生的家长看得到**；可以按日期和场景筛选。
5. **学生档案**：出生日期、性别、过敏 / 健康备注、紧急联系人。老师可以查看学生详情页（档案、家长电话、到离园记录、照片）。
6. **消息中心**：右上角 🔔 显示未读数量，所有通知（到园、离园、照片、缴费、通告、反馈回复）都会留在这里。
7. **建议反馈**：家长和老师可以提交建议、问题、投诉（可附图片），学校回复后会通知对方。
8. **凭证导出**：按校区、班级、日期、状态导出 Excel 表格，或打包下载所有凭证文件（ZIP）；每次导出都有记录。
9. **学校资料与说明**：每间学校的介绍、地址、电话、WhatsApp、上课时间；关于我们、用户协议、隐私政策（附依据 PDPA 的草稿，请学校审阅）。

家长登录后能看到孩子今天几点到园、几点离园，按月份查看历史记录，并收到 App 推送通知。

界面支持 **中文 / English** 切换，手机、电脑都能用，也可以“添加到主屏幕”像 App 一样打开。

每个身份能做什么、不能做什么，请看 [ROLES.md（身份与权限说明）](ROLES.md)。

## 多校区

一个系统管理多间学校（校区）。家长即使有孩子在不同校区，也只需要一个账号。

- **超级管理员**：管理员账号**不选校区** = 管理整个后台和全部学校，也只有他能新增校区
- **学校管理员**：管理员账号**选了校区** = 只能看到和管理那个学校的班级、学生、老师、家长、点名、缴费、通告
- **老师**：只看得到所属校区的学生

## 账号身份

| 身份 | 能做什么 |
|---|---|
| 超级管理员（不选校区的管理员） | 管理整个后台：三间学校的一切，新增 / 修改校区，查看各校概况 |
| 学校管理员（选了校区的管理员） | 管理自己学校：概况、收费项目、审核缴费凭证、发通告、学生 / 班级 / 老师 / 家长账号、学生卡 |
| 老师（门卫也用这个） | 只负责日常：到园 / 离园点名、扫码、上传学生生活照；可以看通告和本校学生资料（档案、家长电话） |
| 家长 | 看孩子到园 / 离园记录、档案、照片、通告，缴费并下载收据 |

学生不需要账号，只需要一张二维码卡。

## 快速试用

需要安装 [Go](https://go.dev/dl/) 1.26 或以上。

```bash
cd school-app
ADMIN_PASSWORD=换成你的密码 go run . -demo
```

用浏览器打开 http://localhost:8080 。

`-demo` 会加入示范数据，可以用下面的账号试：

- 管理员：`admin`，密码是上面 `ADMIN_PASSWORD` 设置的
- 老师：`teacher` / `teacher123`（Tadika Taman Merak）
- 家长：`parent` / `parent123`

正式使用时**不要加 `-demo`**。如果不设置 `ADMIN_PASSWORD`，第一次启动会随机生成管理员密码，显示在启动日志里。

## 正式开始使用的步骤

1. 总管理员登录 → **管理 → 校区**：新增或修改校区名称
2. **管理 → 账号**：新增校区管理员、老师和家长账号（管理员和老师要选校区）
3. **管理 → 班级**：新增班级，选择校区和班主任
4. **管理 → 学生**：新增学生（可以填写档案），并“绑定家长”（一个学生可以绑定多个家长，一个家长也可以有多个孩子）
5. **管理 → 学生卡**：选择班级 → 打印，剪下来发给学生（可以过塑或放进卡套）
6. **管理 → 收费**：建立收费项目，例如每月学费。下个月可以点“复制”，改名称和日期就好
7. 学生卡丢了：在学生列表点“补办卡”，旧卡会立即作废，再打印新卡

## App 推送通知

家长在首页或“我的”页面点“开启通知”，之后会收到：

- **到校通知**：孩子扫码打卡后马上通知（同一个学生一天只通知一次）
- **新照片通知**：老师上传了有自己孩子的照片

Android 手机直接可用。**iPhone 要先用 Safari“添加到主屏幕”，再从主屏幕打开 App 才能开启**（iOS 16.4 或以上）。推送通知免费，不需要额外开通任何服务。管理员可以在 **管理 → 通知记录** 看到每条通知是否发送成功。

## 学生照片

- 老师在 **照片** 页面点“上传照片”，一次可以选多张，然后勾选照片里有哪些学生（合照就选多个）
- 家长只看得到**有自己孩子**的照片；合照里也只显示自己孩子的名字
- 照片会自动压缩（最长边 1920 像素），并**删除照片里的 GPS 位置等资料**
- 老师可以删除自己上传的照片，管理员可以删除任何照片

## Excel 批量导入学生

**管理 → 学生 → 📥 Excel 批量导入**：

1. 下载 Excel 范本，每个学生填一行（学号、姓名、班级、档案、最多两位家长）
2. 选择填好的文件，系统先显示**预览**，每一行是“新学生 / 更新 / 有错误”，错误会写明原因。这时还不会保存任何资料
3. 没有错误才可以按“确认导入”，所有资料一次过保存（失败的话什么都不会保存）

- 班级不存在会自动建立；学号已存在会更新资料（空白栏位不会覆盖原有资料）
- **家长用电话号码配对**：电话已有账号就直接绑定（例如兄弟姐妹在别的学校），没有就建立新账号，用户名是电话号码
- 新家长的初始密码只会出现在导入后下载的 Excel 里，请发给家长，并提醒他们登录后修改密码

## 忘记密码

登录页的“忘记密码？”可以输入用户名、电话或邮箱：

- **账号有邮箱，而且服务器设置了邮件**：系统寄出重设链接（30 分钟内有效，只能用一次）
- **否则**：请求会出现在学校管理员的“概况”页，管理员也会收到推送。管理员按“重设密码”会产生一个临时密码，再通过电话或 WhatsApp 告诉对方

每个人都可以在“我的”页面填写自己的邮箱，以后忘记密码就能自己重设。

### 设置寄信邮箱（可选）

用学校的邮箱寄出重设链接。以 Gmail 为例：先开启“两步验证”，再建立一个“应用专用密码（App password）”。启动时加上：

```bash
SMTP_HOST=smtp.gmail.com SMTP_PORT=587 SMTP_USERNAME=学校邮箱@gmail.com SMTP_PASSWORD=应用专用密码 \
SMTP_FROM="Lovely House <学校邮箱@gmail.com>" ./schoolapp -public-url https://你的网址 ...
```

`-public-url` 是 App 的网址，邮件里的链接会用这个网址。

## 部署到服务器

```bash
cd school-app
go build -o schoolapp .
./schoolapp -data /var/lib/schoolapp -addr :8080 -behind-https
```

⚠️ **一定要用 HTTPS**。手机浏览器只允许 `https://` 网站使用相机，否则无法扫码。最简单的办法是在前面放 [Caddy](https://caddyserver.com/)，它会自动申请免费证书：

```
# Caddyfile
school.你的域名.com {
    reverse_proxy localhost:8080
}
```

也可以直接用 `-tls-cert` 和 `-tls-key` 指定证书文件。

### 启动参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-addr` | `:8080` | 监听地址 |
| `-data` | `./data` | 数据库和上传文件存放的文件夹 |
| `-tz` | `Asia/Kuala_Lumpur` | 学校所在时区（UTC+8），例如 `Asia/Shanghai`、`Asia/Singapore` |
| `-late` | `07:30` | 超过这个时间打卡算迟到 |
| `-currency` | `RM` | 金额前显示的货币 |
| `-behind-https` | 关 | 用 Caddy/Nginx 提供 HTTPS 时打开 |
| `-tls-cert` / `-tls-key` | 无 | 直接使用 HTTPS 证书 |
| `-push-contact` | `admin@example.com` | 学校联络邮箱（推送服务需要），请改成真实邮箱 |
| `-public-url` | 无 | App 的网址，用在重设密码邮件的链接里 |
| `-demo` | 关 | 加入示范数据 |

### 备份

所有资料都在 `-data` 文件夹里：`school.db`（数据库）和 `uploads/`（家长上传的单据和学生照片）。**请定期备份整个文件夹。**

## 界面与语言

- 登录后顶部只显示：问候语与名字（如“晚上好，林先生”）、所属学校（家长显示孩子的学校）、🔔 消息，以及右上角的小 logo
- **第一次登录**会先问要用 中文 还是 English；选好后成为这个账号的默认语言（换手机也一样），并提示以后可在“我的 → 语言”更改
- **退出登录**在“我的”页面最下方

## 一个家庭有几个孩子

系统用“同一个家长账号”认出兄弟姐妹，不需要另外设定。

- **首页**：几个孩子合成一张“今天”卡，每个孩子一行，显示到园 / 离园时间或“未到”
- **扫码打卡**：扫到其中一个孩子，下面会列出同一家庭的其他孩子（已勾选），按一次就一起到园 / 离园；手动搜索打卡也一样。只会列出这位老师有权限的学校的孩子
- **到园 / 离园通知**：15 秒内打卡的兄弟姐妹合成一条通知，例如“林小红、林小华 已于 7:42 到园（准时）”
- **缴费**：顶部显示全家待缴总额；同一间学校的费用可以一起勾选，上传一张转账单。学校确认或退回时会一起处理，每个孩子各有自己的正式收据；“我的收据”可以一次下载全部（一个 PDF）
- **照片**：用小头像切换孩子；照片角落标出是哪个孩子；新照片通知 2 分钟内合并，例如“新照片：林小红 3 张、林小华 2 张”
- **通知**：每则通知标出关于哪个孩子，可以按孩子筛选；推送里写明关于谁
- **需要回复的通知**：发通知时勾选“需要家长回复是否出席”，家长为每个孩子各自回复“会出席 / 不出席”（可以改），管理员在通知下面看到谁出席、谁不出席、谁还没回复

注意：合并中的通知（最多等 15 秒或 2 分钟）保存在内存里，如果刚好在这段时间重启服务器，这几条推送和消息中心的提醒会漏发（打卡记录、照片本身不受影响，家长在首页和照片页照样看得到）。

## 安全说明

- **密码**：至少 8 位，不能是常见密码（如 12345678、password123），不能包含用户名或电话号码；以 bcrypt（cost 12）加密保存
- **登录**：连续输错 8 次锁定 15 分钟；同一网络地址每 15 分钟最多 30 次；账号存在与否，回应和时间都一样
- **登录状态**：数据库只保存登录凭证的哈希值，资料库外泄也不能用来登录；管理员 7 天、老师 30 天、家长 90 天需要重新登录；改密码会登出其他设备
- **安全记录**：登录成功 / 失败、密码修改与重设、账号建立 / 禁用 / 删除都有记录（管理 → 安全记录）
- **浏览器安全设定**：严格的内容安全政策（CSP）、HTTPS 时启用 HSTS 与 `__Host-` cookie、禁止被其他网站嵌入、跨来源隔离（COOP / CORP）、防 CSRF
- **资料权限**：家长只能看自己孩子的资料；合照只给照片中孩子的家长；老师只看自己学校；学校管理员只管自己学校
- **上传文件**：只接受图片或 PDF；照片会重新编码并删除 GPS 位置等资料；文件需要登录并有权限才能打开
- 二维码里是随机密码，不是学号，无法伪造别人的卡

## 技术结构

- 后端：Go + SQLite，编译出来是一个程序文件，网页也打包在里面
- 前端：原生 JavaScript，没有构建步骤（`web/` 文件夹）
- 扫码：[jsQR](https://github.com/cozmo/jsQR)（Apache-2.0），在手机浏览器里识别二维码
