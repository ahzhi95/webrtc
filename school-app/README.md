# 校园通 School App

给幼儿园（多个校区）用的手机网页 App：

1. **到园 / 离园**：老师在班级名单上勾选点名（时间自动填入，可以修改，提交前确认），或者扫学生的二维码卡。超过设定时间会标记“迟到”。修改已提交的时间必须填写原因，并保留修改记录。
2. **通知**：发给全部学校、某个校区或某个班。
3. **缴费**：学校建立收费项目（月费、活动 / 临时收费、杂费），发给整个校区、一个班或指定学生，并设定截止日期。家长勾选已付的项目，上传一张凭证；学校确认后项目变成“已缴”，退回时必须写原因。也可以记录现金付款、免缴，或修改个别学生的金额。
4. **学生照片**：老师上传照片并选出照片里有哪些学生，**只有这些学生的家长看得到**。
5. **学生档案**：出生日期、性别、过敏 / 健康备注、紧急联系人。老师可以查看学生详情页（档案、家长电话、到离园记录、照片）。

家长登录后能看到孩子今天几点到园、几点离园，按月份查看历史记录，并收到 App 推送通知。

界面支持 **中文 / English** 切换，手机、电脑都能用，也可以“添加到主屏幕”像 App 一样打开。

## 多校区

一个系统管理多间学校（校区）。家长即使有孩子在不同校区，也只需要一个账号。

- **总管理员**：管理员账号**不选校区** = 可以管理全部学校，也只有总管理员能新增、修改校区
- **校区管理员**：管理员账号**选了校区** = 只能看到和管理那个校区的班级、学生、老师、家长、点名、缴费、通知
- **老师**：只看得到所属校区的学生

## 账号身份

| 身份 | 能做什么 |
|---|---|
| 管理员（总管理员 / 校区管理员） | 所有功能，另外可以管理校区、班级、学生、账号、收费项目，打印学生卡，审核缴费凭证 |
| 老师（门卫也用这个） | 点名、扫码、修改记录、查看学生档案和家长电话、上传照片、发布通知 |
| 家长 | 看孩子到园 / 离园记录、档案、照片、通知，缴费并上传凭证 |

学生不需要账号，只需要一张二维码卡。

## 快速试用

需要安装 [Go](https://go.dev/dl/) 1.26 或以上。

```bash
cd school-app
ADMIN_PASSWORD=换成你的密码 go run . -demo
```

用浏览器打开 http://localhost:8080 。

`-demo` 会加入示范数据，可以用下面的账号试：

- 管理员：`admin`，密码是上面 `ADMIN_PASSWORD` 设置的
- 老师：`teacher` / `teacher123`（Tadika Taman Merak）
- 家长：`parent` / `parent123`

正式使用时**不要加 `-demo`**。如果不设置 `ADMIN_PASSWORD`，第一次启动会随机生成管理员密码，显示在启动日志里。

## 正式开始使用的步骤

1. 总管理员登录 → **管理 → 校区**：新增或修改校区名称
2. **管理 → 账号**：新增校区管理员、老师和家长账号（管理员和老师要选校区）
3. **管理 → 班级**：新增班级，选择校区和班主任
4. **管理 → 学生**：新增学生（可以填写档案），并“绑定家长”（一个学生可以绑定多个家长，一个家长也可以有多个孩子）
5. **管理 → 学生卡**：选择班级 → 打印，剪下来发给学生（可以过塑或放进卡套）
6. **管理 → 收费**：建立收费项目，例如每月学费。下个月可以点“复制”，改名称和日期就好
7. 学生卡丢了：在学生列表点“补办卡”，旧卡会立即作废，再打印新卡

## App 推送通知

家长在首页或“我的”页面点“开启通知”，之后会收到：

- **到校通知**：孩子扫码打卡后马上通知（同一个学生一天只通知一次）
- **新照片通知**：老师上传了有自己孩子的照片

Android 手机直接可用。**iPhone 要先用 Safari“添加到主屏幕”，再从主屏幕打开 App 才能开启**（iOS 16.4 或以上）。推送通知免费，不需要额外开通任何服务。管理员可以在 **管理 → 通知记录** 看到每条通知是否发送成功。

## 学生照片

- 老师在 **照片** 页面点“上传照片”，一次可以选多张，然后勾选照片里有哪些学生（合照就选多个）
- 家长只看得到**有自己孩子**的照片；合照里也只显示自己孩子的名字
- 照片会自动压缩（最长边 1920 像素），并**删除照片里的 GPS 位置等资料**
- 老师可以删除自己上传的照片，管理员可以删除任何照片

## 部署到服务器

```bash
cd school-app
go build -o schoolapp .
./schoolapp -data /var/lib/schoolapp -addr :8080 -behind-https
```

⚠️ **一定要用 HTTPS**。手机浏览器只允许 `https://` 网站使用相机，否则无法扫码。最简单的办法是在前面放 [Caddy](https://caddyserver.com/)，它会自动申请免费证书：

```
# Caddyfile
school.你的域名.com {
    reverse_proxy localhost:8080
}
```

也可以直接用 `-tls-cert` 和 `-tls-key` 指定证书文件。

### 启动参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-addr` | `:8080` | 监听地址 |
| `-data` | `./data` | 数据库和上传文件存放的文件夹 |
| `-tz` | `Asia/Kuala_Lumpur` | 学校所在时区（UTC+8），例如 `Asia/Shanghai`、`Asia/Singapore` |
| `-late` | `07:30` | 超过这个时间打卡算迟到 |
| `-currency` | `RM` | 金额前显示的货币 |
| `-behind-https` | 关 | 用 Caddy/Nginx 提供 HTTPS 时打开 |
| `-tls-cert` / `-tls-key` | 无 | 直接使用 HTTPS 证书 |
| `-push-contact` | `admin@example.com` | 学校联络邮箱（推送服务需要），请改成真实邮箱 |
| `-demo` | 关 | 加入示范数据 |

### 备份

所有资料都在 `-data` 文件夹里：`school.db`（数据库）和 `uploads/`（家长上传的单据和学生照片）。**请定期备份整个文件夹。**

## 安全说明

- 密码使用 bcrypt 加密保存；连续输错 8 次会锁定 15 分钟
- 二维码里是随机密码，不是学号，无法自己伪造别人的卡
- 家长只能看到自己孩子的资料和单据；单据文件需要登录才能打开
- 上传文件只接受 JPG / PNG / WEBP / PDF，最大 10 MB

## 技术结构

- 后端：Go + SQLite，编译出来是一个程序文件，网页也打包在里面
- 前端：原生 JavaScript，没有构建步骤（`web/` 文件夹）
- 扫码：[jsQR](https://github.com/cozmo/jsQR)（Apache-2.0），在手机浏览器里识别二维码
