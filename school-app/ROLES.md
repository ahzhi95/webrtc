# Lovely House：身份与权限说明

本文件说明 App 里每个身份**能做什么**、**不能做什么**，以及**还缺哪些功能**。

适用学校：Tadika Taman Merak、Tadika Merak Pintar、Tadika Merak Cemerlang

---

## 身份一览

| 身份 | 怎么建立 | 管理范围 |
|---|---|---|
| **超级管理员** | 管理员账号，**不选校区** | 整个后台和全部学校 |
| **学校管理员** | 管理员账号，**选了校区** | 只限自己的学校 |
| **老师** | 老师账号，选所属学校（门卫也用老师账号） | 只限自己的学校 |
| **家长** | 家长账号，再绑定到孩子 | 只限自己的孩子 |

学生不需要账号，每人一张二维码卡。

---

## 1. 超级管理员

### ✅ 能做
- **概况**：查看三间学校的今天到园和缴费状况，可以并排比较，也可以切换到单一学校
- **校区**：新增校区、改校名，填写收据资料（注册编号、地址、电话、邮箱、收据前缀）
- **账号**：**只有超级管理员**可以建立和管理管理员账号；也可以建立任何学校的老师、家长；把账号调到另一间学校；修改、禁用 / 启用、重设密码、删除
- **通告**：可以发给**全部学校**、某间学校或某个班
- **关于我们、用户协议、隐私政策**：只有超级管理员可以修改
- **学校管理员能做的一切**（见第 2 节），而且适用于三间学校

### ❌ 不能做（系统刻意限制）
- 不能把自己的账号限制在一个校区，也不能禁用或删除自己，以免把自己锁在外面
- 不能删除还有班级的校区
- 不能删除已经有人付款的收费项目（可以改为“免缴”）
- 不能删除或修改已开出的收据号码，只能“作废”

## 2. 学校管理员

### ✅ 能做（只限自己学校）
- **概况**：本校今天到园（各班明细）、待审核的付款凭证、逾期未缴、本月已收
- **班级**：新增、修改、删除，指定班主任
- **学生**：新增、修改、删除，填写学生档案，绑定 / 解绑家长，补办学生卡，打印二维码卡
- **账号**：建立本校的老师和家长账号；修改、禁用 / 启用、重设密码
- **批量导入**：用 Excel 一次导入学生和家长
- **密码重设请求**：在“概况”页处理本校用户的忘记密码请求，产生临时密码
- **安全记录**：查看本校账号的登录、失败尝试和账号变更
- **收费**：
  - 建立收费项目（月费、活动 / 临时收费、杂费、其他），发给全校、某个班或指定学生，并设定截止日期
  - 查看谁已缴、谁未缴，以及已收和未收金额
  - 记录现金付款、免缴，或修改个别学生的金额
  - 超过一个月未缴时按“提醒”，通知还没缴费的家长（12 小时内只能提醒一次）
- **审核付款凭证**：确认后系统自动开立正式收据；退回时必须写原因
- **凭证导出**：按班级、日期、状态导出 Excel 表格或 ZIP 文件包，每次导出都会记录
- **反馈**：查看本校家长和老师的反馈、回复、标记处理中 / 已解决
- **学校资料**：修改本校的介绍、WhatsApp、上课时间
- **通告**：发给本校或本校某个班；附图片 / PDF、定时发布、修改、撤回、删除；查看谁已读、谁未读
- **点名和扫码**，修改点名时间（必须写原因）
- **照片**：上传和删除本校的照片
- **校区资料**：修改本校的地址、电话、邮箱、注册编号、收据前缀（不能改校名）
- **推送记录**：只看本校的

### ❌ 不能做
- 看不到也改不了其他学校的任何资料
- 不能新增校区，也不能改校名
- 不能建立、修改、禁用或删除**管理员**账号（只有超级管理员可以）
- 不能把通告发给全部学校
- 不能把账号或学生调到别的学校
- 看不到其他学校的家长账号。如果一个家庭有孩子在两间学校，要请**超级管理员**把家长绑定到第二个孩子，避免同一位家长有两个账号

## 3. 老师

### ✅ 能做（只限自己学校）
- **到园 / 离园点名**：在班级名单上勾选（时间自动填入，可以修改，提交前确认），或扫学生的二维码卡
- **忘记带卡**：搜索学生姓名，手动打卡
- **修改点名时间**：必须写原因，修改记录会保留，老师和家长都看得到
- **查看学生详情**：学生档案（过敏 / 健康备注、紧急联系人）、家长电话和邮箱、到离园记录、照片
- **上传生活照**：一次可以选多张，选出照片里有哪些学生、场景（上课、户外活动……）和拍摄日期，**只有这些学生的家长看得到**；可以删除自己上传的照片
- **提交反馈**给学校，并看到学校的回复
- 看通告，修改自己的资料和密码，开启推送通知

### ❌ 不能做
- 发通告、删除通告
- 看缴费、付款凭证、收据
- 新增或修改学生、班级、账号，修改学生档案
- 删除别人上传的照片
- 看到其他学校的学生

## 4. 家长

### ✅ 能做（只限自己的孩子）
- **首页**：每个孩子今天几点到园、几点离园；待缴费用提醒；最新照片和通告
- **推送通知**：孩子到园、离园、有新照片、有新收费项目、缴费被确认或退回
- **孩子详情**：学生档案（只能看）、按月份的到离园记录（包括录入老师和修改记录）、照片、缴费记录
- **照片**：只看到有自己孩子的照片，合照里也只显示自己孩子的名字；可以下载
- **通告**：发给全部学校的、孩子所在学校的、孩子班级的；可以打开附件；未读的会标示“新”
- **消息中心**：右上角 🔔 查看所有通知
- **建议反馈**：提交建议、问题、投诉（可附图片），收到学校的回复
- **学校资料**：学校地址（可打开地图）、电话、WhatsApp（可直接聊天）、上课时间
- **缴费**：
  - 看待缴项目、金额和截止日期
  - 勾选多个项目，一次上传一张付款凭证
  - 上传不在列表里的其他付款
  - 查看审核结果和退回原因
- **正式收据**：学校确认后可以下载 PDF 或图片，也可以直接分享（例如转发到 WhatsApp）
- 修改自己的名称、电话、邮箱；修改密码；选择界面语言（中文 / English）；忘记密码时自己重设（有邮箱）或请学校重设
- 切换中文 / English

### ❌ 不能做
- 修改孩子的档案
- 看到其他孩子的任何资料
- 上传照片
